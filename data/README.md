### Zeros of $p$-adic $L$-functions and Refined Random Matrix Conjectures

#### Directory with data files ####
---

Larger txt files are compressed using `zip -9`. Each file contains data for a specific range of conductors, prime and Teichmuller twist, e.g. `10h7-p3t1` for conductors $<10^7$, $p=3$ and twist $1$.   

Usually all characters with $\lambda_p \geq 1$ are printed out, e.g.:   
`p=3, twist=1, Fundamental Discriminant=-31 ==> lambda=1, slopes=[1]`

For the discriminants of the characteristic polynomial, we only look at characters with $\lambda_p =2$.   

The last line of each file contains a summary, e.g.:   
`p=3, twist=1, distribution-lambda=[666928, 307495, 108810, 37527, 12745, 4263, 1388, 470, 162, 51, 17, 4, 1, 1, 1]`
